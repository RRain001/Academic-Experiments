# Kincaid：高架浮力烟羽 SF₆ / SO₂

**场址**：美国伊利诺伊州 Kincaid 发电站；**高度**：约 187 m 排放烟囱；1980–1981 年实验。

- **SF₆**：受控高架示踪释放，有地面受体弧线浓度、逐小时气象，适合 CALPUFF 类型烟团抬升与扩散；实验时段与接收时间窗需按选定子集核实。
- **SO₂**：独立的烟囱排放/监测数据库，不可将 SO₂ 化学/沉积效应和 SF₆ 惰性示踪混为一组观测。
- **对第四章的限制**：高架强浮力烟羽、受体可在数十公里；并非几公里内建筑尾流或氚土壤验证的首选。

## 权威数据入口
- [EPA AERMOD 模型评估数据库（Kincaid SF6 / SO2 ZIP）](https://www.epa.gov/scram/air-quality-dispersion-modeling-preferred-and-recommended-models)。
- [HARMO Kincaid 原始数据及衍生资料说明](https://harmo.org/jsirwin/KincaidHourlyDiscussion.html)；[HARMO 数据集目录](https://harmo.org/classic.php)。

**数据状态**：公开 ZIP 入口已核实，但 **ZIP 内具体文件、原始浓度与评价软件输出的对应关系还没有逐项审计**；不得声称已取得和解析完整观测。下一步先清点 SF₆ 源项、采样弧线、逐时风与小时平均地面浓度，采用独立留出试验日验证。

**第三章**：高架浮力烟羽、峰值和弧线最大值、1h 平均浓度；不验证氚跨介质过程。
