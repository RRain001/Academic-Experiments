# Copenhagen Tracer Experiments（1978–1979）

丹麦 Copenhagen / Gladsaxe，**SF₆ 从 115 m 塔上非浮力释放**，下风向约 **2–6 km** 的受体弧线；实验主要覆盖中性、不稳定边界层，观测含气象塔及三维风速波动，浓度常按连续 **20 min** 时窗采样。

## 权威文献
- [DTU：The Copenhagen tracer experiments: Reporting of measurements](https://orbit.dtu.dk/en/publications/the-copenhagen-tracer-experiments-reporting-of-measurements/)。
- [DTU：Elevated Source SF6-Tracer Dispersion Experiments in the Copenhagen Area（Risø-R-446）](https://orbit.dtu.dk/en/publications/elevated-source-sfsub6sub-tracer-dispersion-experiments-in-the-co/)。

## 验证价值
- **第三章 P1**：无浮力高架烟团扩散、不同大气稳定度、20 min 弧线浓度。
- **第四章 P1**：城市粗糙下垫面非中性 ABL、速度/湍流气象边界验证；不是局地建筑解析或 HTO 沉积的直接证据。
- 必须区分 20 min 采样窗与 CFD 子秒/秒级数值时间步。

**数据状态**：原始测量汇编报告可定位；未完成逐事件机器可读转换与许可审查，L0。
