# Hanford 系列大气扩散试验：选子集而非混为一个数据集

美国 Washington 州 Hanford 野外扩散研究至少包括 **Green Glow（1959）**、**30-Series（1960–1962）**、**67-Series（1967–1973）** 等不同源高、示踪物、采样布设与气象工况。不可把系列整体视作单一验证样本。

## 资料
- [Hanford 67-Series，1977 原始数据汇编，103 次示踪释放，UNT](https://digital.library.unt.edu/ark:/67531/metadc1074412/)。
- [EPA Hanford 67-Series 数据档案说明](https://nepis.epa.gov/Exe/ZyPURL.cgi?Dockey=2000X4ER.TXT)。
- [Hanford Green Glow 实验与 1959–1974 历史综述](https://www.sciencedirect.com/science/article/pii/0004698185901386)。

## 使用选择
- **第三章 P2**：先选 Green Glow / 30-Series 的近地面释放或 67-Series 中单一明确的高架工况，验证不同距离的烟羽和垂直采样。
- **第四章 P2**：如果出现可复算的近地面多高度浓度、气象剖面及背景数据，可用作额外非建筑地形 CFD 验证。
- 历史使用的示踪物包括 ZnS 等；以每次 trial 的报告为准，不能对所有事件笼统写 SF₆。
