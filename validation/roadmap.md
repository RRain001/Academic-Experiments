## 实施任务分解

### E1：把 Kincaid / Prairie Grass 从“链接”变成可运行案例（第三章先行）

1. 从 [EPA 模型评估数据库](https://www.epa.gov/scram/air-quality-dispersion-modeling-preferred-and-recommended-models) 分别取得 Kincaid **SF₆** 和 Prairie Grass ZIP；禁止将 EPA 模型预测结果标成观测。
2. 解包生成含原文件名、大小、SHA256、来源 URL、许可信息的 manifest；观察每一字段/单位。
3. 单独整理释放源时序、源高、地形/粗糙度、受体弧线坐标、风速/风向/稳定度及采样平均窗口。
4. 仅当至少一个 trial 可以独立重建时，提交 `BENCHMARK_READY` 候选；为训练/参数选择和完全独立的验证 trial 预分组。
5. 第三章检验普通大气扩散，不在此阶段验证 HT/HTO 氧化。

### E3：第四章首先验证 ABL/被动标量，再做多介质

1. 用 Prairie Grass 建立无建筑、观测驱动的 OpenFOAM URANS 案例：先检验中性 ABL，之后引入稳定/不稳定条件。
2. MUST 选 **一项数据完整 trial**；重建 120 容器几何与相应源项，必要时优先参考已有论文展示的案例，但必须以同一 trial 的观测为依据。
3. 确认现场风速/风向/温度与稳定度：单站不足以约束复杂边界时记录参数化依赖和敏感性。
4. 对风、被动标量、非稳态源项分别评估；URANS 预测的平均场与同平均窗口的现场浓度对照。
5. 记录网格数、最小单元尺度、CFL、流动 spin-up、总模拟时长、wall-clock、核数和收敛/守恒。
6. JU03 仅在 MUST 通过且资料可获取时考虑，不得拖延多介质主线。

### E4–E5：氚多介质验证

1. **1987 HT**：从 JAERI-M 88-232 提取源项与实测 HT、空气 HTO、土壤 HTO 和植物数据；校验当前六行 5min 气象表是否与采样时区/风向定义一致。
2. **1994 持续 HT**：逐页整理 JAERI-Data/Code 99-022 的气象、土壤、空气数据，补齐植物 TFWT/OBT 论文数据；单列 8.8/13 TBq 冲突，不回填臆造总量。
3. **1992 Canada HTO**：针对不同位置分别核对背景、浓度、地表水汽通量及土壤再释放；识别“测得”和“按湍流模型推导”的通量。
4. 先用离线界面/土壤/植物模块进行时序守恒与观测检验，再与 OpenFOAM 大气相耦合。**同一物理通量只交换一次，守恒检查同单位同积分时间窗**。
5. HT → HTO 的土壤氧化是单独过程；不能用空气 HTO 直接增量代替；植物 TFWT / OBT 的组织、干鲜质量、可食部分开。
6. 食物链/剂量另找农业转移和权威剂量系数验证基准；现有野外示踪数据并不能证成整条食物链。

## 关键阻塞项（必须公开）

- 1994 HT 总活动量 **8.8 vs 13 TBq**；开放问题编号 `CR94-TOTAL`。
- 恰克河完整空气/土壤/植物观测尚未抽取，并非开源现成完整数据集。
- MUST、JU03 原始数值资料当前可达性和许可未知。
- ABL 气象边界单站/多站代表性、非中性参数、湍流闭合及风廓线验证。
- 1992 地表 HTO 研究是污染环境下通量研究，不等于已知一次排放量。

## 每个 case 必须交付

`case_manifest.yaml`、原件及 SHA256、转换脚本+单元检查、气象/源/监测站表、模型配置与 commit、独立 test split、网格/时间步/边界检查、守恒预算、逐观测 predicted-vs-observed 配对、FB/NMSE/FAC2（适用时）、不确定性与阻塞项、科学结论限定说明。

计算尚未进行时统一标记 `NOT_RUN`。如果某实验只有论文图与缺失完整采样定义，标记 `NOT_BENCHMARK_READY`；不能默认为通过。
